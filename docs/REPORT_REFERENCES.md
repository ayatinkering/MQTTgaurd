## Corrections established during dataset inspection

The original dataset creators are Aqachtoul et al. The official release README identifies the Data in Brief article (DOI 10.1016/j.dib.2025.111897) as the dataset publication. Cite it and the Mendeley dataset for data attribution. Reference [14] is a separate benchmark paper; its publisher title is *MQTTEEB-D: A high-fidelity benchmark for real-time MQTT anomaly detection using machine learning techniques* (DOI 10.1016/j.adhoc.2025.104062), rather than the shortened title transcribed above. This correction does not independently validate the other entries.
